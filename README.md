### для разработчиков
словарь DEFAULTS содержит настройки по умолчанию

методы в классе Settings:
* ```get(self, name: str) -> Any``` принимает на вход имя настройки, возвращает значение настройки
* ```set(self, name: str, value: Any) -> None:``` принимает на вход имя настройки и ее новое значение. Меняет значение настройки на то которое было выбрано, но чтобы принять надо вызвать метод save()
* ```save(self) -> None:``` после вызова настройки заданные с помощью set() применяются и сохраняются в файл
* ```reload(self) -> None:``` отклоняет значения выбранные с помощью set(), записывает значения из файла в _data
* ```reset_all(self) -> None:``` после вызова все настройки сбрасываются до заводских
* ```reset(self, name: str) -> None:``` сбрасывает только 1 настройку до заводского значения, имя этой настройки надо передать как аргумент

## система профилей
### что такое система профилей?
**коротко:** система профилей нужна чтобы обрабатывать разные ссылки по разному, например выбрать какие ссылки скачать как .opus а какие как mp4
### что такое профиль?
**требования к профилям:**
* профиль обязательно должен находится в папке профилей, выбрать папку в которой хранятся все профили можно выбрать в настройках(см. выше в разделе "настройки")

* профиль должен **обязательно** содержать **sources.txt**(список ютуб ссылок, по желанию можно писать комментарии с помощью "#"), а так же **ytdlp_args.json**(содержит список аргументов для yt-dlp, можно выбрать куда будет сохранена музыка из этого профиля или в каком формате она будет скачана)
