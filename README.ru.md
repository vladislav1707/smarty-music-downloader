# Что это и зачем оно надо

проект использует [лицензию MIT](LICENSE)

**Краткое описание:** эта программа нужна чтобы 
массово скачивать музыку/видео с ютуба с помощью yt-dlp, программа абсолютно бесплатная и с открытым исходным кодом. Тут есть уникальная система профилей и ротация прокси. **Несмотря на название программы поддерживается скачивание видео**

**Внимание:** программа имеет смысл в долгосрочной перспективе, если у вас мало файлов то она лишь замедлит процесс, **НО** если у вас огромные плейлисты и куча ссылок это очень поможет так как программа обходит временные баны по IP и ошибку 429

**фичи:**
* встроенная проверка прокси (ОЧЕНЬ БЫСТРАЯ)

* при каждой ошибке прокси меняется (обходит временные баны по IP от ютуба)

* есть система профилей (разные ссылки с разными аргументами)

* есть рабочий GUI (СЫРОЙ)

* можно настроить сортировку по папкам (в профиле)

* этот проект опенсорсный и ПОЛНОСТЬЮ БЕСПЛАТНЫЙ

* Если вам что то не нравится или не хватает вы можете добавить это сами. Например покрасить все в розовый поменяв код или добавить новые кнопки. Из простого можно сменить тему с clam на alt

* если видео удалят и оно у вас скачано то оно никуда не исчезнет

* есть несколько готовых к использованию пресетов профилей

* поддерживается скачивание как музыки так и видео

# Установка
## Windows
просто скачайте архив с последней версией и распакуйте его куда душе угодно, там будут 2 исполняемых файла, GUI версия и CLI, CLI версия более завершенная и я советую использовать именно ее
## Linux
1. убедитесь, что установлен Python 3.8 или выше

2. скачайте исходный код, перейдите в папку с CLI.py и GUI.py и запустите командой py или python:
* ```py CLI.py --help``` выведет список команд CLI версии

* ```py GUI.py``` запустит GUI версию

Если хотите быстро запускать можете добавить alias например или придумать еще что то. Если хотите дополнить эту инструкцию пишите мне
## Mac OS
процесс как для linux, но если что то не работает то попробуйте ввести команду:
```brew install ffmpeg``` она установит ffmpeg

# Настройки
В настройках можно менять некоторые штуки вроде profiles_dir, кол-во потоков на скачивание и подобных, если вы ищете где изменить настройки ytdlp или добавить ссылки для скачивания ищите в [описании системы профилей](#Система-профилей)
## Где менять настройки
либо через CLI, либо искать data а там settings.json и вводить туда настройки
## Доступные настройки
```proxy_url``` вставьте ссылку на raw список прокси, по умолчанию использует SOCKS5 прокси от proxifly
```profiles_dir``` директория в которой будет производится поиск профилей
```proxy_refresh_interval``` как часто будет скачиваться список прокси с интернета(по умолчанию каждые 5 минут 5 секунд)
```proxy_cleanup_interval``` как часто будет очищаться список рабочих прокси(это нужно из за слишком быстрой проверки, 0 отключает очистку)
```max_validation_threads``` кол-во потоков которые будут валидировать прокси, рекомендую не трогать

# Система профилей
Все профили **ОБЯЗАТЕЛЬНО** должны быть в 1 директории(папке), иначе программа их просто не увидит. Указать ее можно в настройках(настройка называется profiles_dir, если указать "profile_presets" тогда программа будет видеть профили в папке с пресетами, это значение по умолчанию)
## Что такое профиль
Профили содержат ссылки и аргументы, ссылки профиля будут скачаны с аргументами профиля, аргументы других профилей не распространяются на этот профиль и наоборот
## Как создать профиль
Вы можете создать профиль к примеру из пресета, просто скопируйте его к себе в директорию профилей, назовите как хотите, запишите в sources.txt свои ссылки(и комментарии к ним по желанию) а так же если посчитаете нужным поменяйте аргументы в ytdlp_args.json
# Команды для CLI
**внимание:** тут примеры для windows, если у вас linux то просто замените SMDownloader_CLI.exe на что то свое и все будет работать так же

тут лишь список самых полезных команд, чтобы получить список всех команд введите ```SMDownloader_CLI.exe --help```
## Разное
* ```SMDownloader_CLI.exe --help``` показать список команд

* ```SMDownloader_CLI.exe --version``` показать версию

## Настройки

* ```SMDownloader_CLI.exe settings --show_all``` показать все настройки

* ```SMDownloader_CLI.exe settings --set "параметр" "значение"``` меняет настройки

* ```SMDownloader_CLI.exe settings --get "параметр"``` выведет значение параметра

## Профили
* ```SMDownloader_CLI.exe profiles --list``` выведет список найденных профилей

## Скачивание
* ```SMDownloader_CLI.exe download --all``` обработать ссылки из всех профилей

* ```SMDownloader_CLI.exe download --profile "имя"``` обработать ссылки только из 1 профиля

# Часто задаваемые вопросы (FAQ)
## Как мне добавить ссылки для скачивания?
Для начала вам нужен профиль, вы можете использовать пресеты или создать профиль на основе пресетов:
1. ```music_opus``` профиль для скачивания музыки в формате opus, если вам нужен mp3 то на его основе можно сделать и такой профиль
2. ```video_mp4``` профиль для скачивания видео в формате mp4
Определились с профилем/создали свой? Отлично, вот как добавить в профиль ссылки:
1. найдите sources.txt или создайте если в профиле его нет
2. запишите нужные вам ссылки (1 ссылка на 1 строку)
3. по желанию добавьте комментарии(комментарий занимает всю строку и начинается на #)

## GUI фигня, где настройки?
Настроить программу можно через CLI или data/settings.json, так как GUI сырой и там нет настроек

## Зачем мне еще один интерфейс для yt-dlp?
Главная цель проекта это не интерфейс а ротация прокси, тут есть CLI версия помимо GUI

## Медленное скачивание
Медленно так как по умолчанию используется бесплатный список прокси, я попытался выжать из него все соки и поэтому поиск рабочих прокси очень быстрый. В долгосрочной перспективе не так медленно благодаря обходу ошибки 429(Too many requests). Если вы хотите скачать пару тысяч файлов(как я) тогда проект вполне норм, но если у вас всего пару файлов которые надо скачать этот проект не имеет смысла
