# модуль settings
## задачи модуля settings
этот модуль должен получать и устанавливать значения в настройках
## методы класса settings
* ```get(self, name: str) -> Any``` принимает на вход имя настройки, возвращает значение настройки
* ```set(self, name: str, value: Any) -> None:``` принимает на вход имя настройки и ее новое значение. Меняет значение настройки на то которое было выбрано, но чтобы принять надо вызвать метод save()
* ```save(self) -> None:``` после вызова настройки заданные с помощью set() применяются и сохраняются в файл
* ```reload(self) -> None:``` отклоняет значения выбранные с помощью set(), записывает значения из файла в _data
* ```reset_all(self) -> None:``` после вызова все настройки сбрасываются до заводских
* ```reset(self, name: str) -> None:``` сбрасывает только 1 настройку до заводского значения, имя этой настройки надо передать как аргумент
