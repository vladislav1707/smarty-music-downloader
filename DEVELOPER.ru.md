# модуль settings
## задачи модуля settings
этот модуль должен получать и устанавливать значения в настройках
## конструктор класса settings
\_\_init\_\_(self):
* Не принимает аргументы

* При создании может создавать settings.json если ее нет, а так же если отсутствуют обязательные настройки заменить их на значения по умолчанию.

## DEFAULTS
DEFAULTS это словарь с настройками по умолчанию, искать в core/settings.py

## методы класса settings
* ```get(self, name: str) -> Any``` принимает на вход имя настройки, возвращает значение настройки
* ```set(self, name: str, value: Any) -> None:``` принимает на вход имя настройки и ее новое значение. **Для применения требуется вызвать save()**
* ```save(self) -> None:``` после вызова настройки заданные с помощью set() применяются и сохраняются в файл
* ```reload(self) -> None:``` отклоняет значения выбранные с помощью set(), записывает значения из файла в _data
* ```reset_all(self) -> None:``` после вызова все настройки сбрасываются до заводских. **Для применения требуется вызвать save()**
* ```reset(self, name: str) -> None:``` сбрасывает только 1 настройку до заводского значения, имя этой настройки надо передать как аргумент. **Для применения требуется вызвать save()**

# модуль profile_manager
**важно:** все профили находятся в 1-ой директории, эта директория указана в настройках(называется profiles_dir), иначе программа их не видит 
## задачи модуля profile_manager
этот модуль должен уметь читать профили: профиль это директория с sources.txt(список ютуб ссылок с комментариями) и ytdlp_args.json
## конструктор класса ProfileManager
\_\_init\_\_(self, settings: Settings):
* Принимает на вход ссылку на экземпляр класса настроек

* При создании сохраняет настройки в приватное поле, чтобы часть измененных настроек была применена может потребоваться перезапустить программу

* Если profiles_dir это "profile_presets" то ищет директорию с пресетами в корневой директории программы, так же это значение по умолчанию но я **настоятельно рекомендую** сменить путь на абсолютный к своей директории со своими профилями, так же можно скопировать туда пресеты из для удобства из "Smarty Music Downloader\profile_presets"

## методы класса ProfileManager
* ```get_links(self, name: str) -> List[str]``` после вызова возвращает список ссылок для скачивания в этом профиле. Если файла нет вернет пустой список
* ```get_all_links(self) -> List[str]:``` после вызова возвращает список ссылок из каждого профиля в profiles_dir
* ```get_ytdlp_args(self, name: str) -> dict``` после вызова возвращает аргументы для yt-dlp в конкретном профиле в виде словаря(ключ это аргумент а значение это значение аргумента). Если файла нет программа завершится с ошибкой
* ```list_profiles(self) -> List[str]:``` выводит список доступных профилей
* ```profile_exists(self, name: str) -> bool:``` принимает на вход имя профиля и возвращает булевое значение в зависимости от существования профиля
* ```profile_path(self, name: str) -> Path:``` принимает на вход имя профиля и возвращает к нему путь

# модуль proxy_manager

Этот модуль должен возвращать по запросу список прокси

## конструктор класса ProxyManager
\_\_init\_\_(self, settings: Settings):
* Принимает на вход ссылку на экземпляр класса настроек

* Делает еще пару мелких действий(проверка на ошибки, запись url в приватное поле)
## методы класса ProxyManager
* ```fetch_proxies(self) -> List[str]:``` возвращает список содержащий прокси
